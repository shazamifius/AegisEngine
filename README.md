# AegisEngine

Un petit projet d'expérimentation et d'apprentissage autour d'un moteur de rendu 3D basé sur Vulkan 1.4 Native en Rust.

*A minimal, experimental 3D rendering engine built with Vulkan 1.4 Native in Rust for testing and educational purposes.*

---

## 🛠️ À propos / About

Ce projet est un bac à sable technique en cours de construction. Il sert à explorer les fonctionnalités de Vulkan 1.4 Native, les shaders WGSL/SPIR-V, les buffers de transmission multi-passes et les algorithmes de rendu graphique.

---

## 🚀 Utilisation / Usage

Pour exécuter le projet localement :

```bash
./run.sh
```

Pour exécuter le mode capture d'écran autonome :

```bash
./run.sh --screenshot
```
